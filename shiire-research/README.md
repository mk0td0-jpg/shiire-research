# 仕入れリサーチ

セカンドストリート・ブランディア・トレファクファッション・買取王国・オフモールの
**公開されている商品情報**を、1つの画面にまとめて表示する仕入れリサーチ用サイトです。

スマホのブラウザでURLを開くだけで使えます。ログインは不要です。

---

## 1. 何ができるか

- ブランドボタンを押すと、各サイトの商品を**1つの一覧に混ぜて**表示
- 上部に**サイトごとの取得状況**（✅取得成功42件／🔄取得中／⚠️失敗／🔗自動取得不可）と**最終更新 ○分前**
- カードに 画像・ブランド・商品名・税込価格・サイズ・状態・販売サイト・**取得日時**を表示
- カードをタップすると、元の商品ページが新しいタブで開く
- 並び替え：**新着順／価格が安い順／価格が高い順**
- 絞り込み：**販売中のみ**／販売サイト／価格／サイズ／キーワード
- **× 興味なし**：一覧から消える（ブラウザを閉じても維持）
- **☆ お気に入り** と **◎ 仕入れ候補**（予想販売価格とメモを入れると**予想利益を自動計算**）
- **NEW**：前回見たときより後に増えた商品に印（「NEWのみ」で新着だけ表示）
- **⚙ 設定画面からブランドの追加・変更ができます**（コードを触る必要はありません）
- **ホーム画面に追加**すると、アプリのように開けます（PWA）

お気に入り・仕入れ候補・興味なし・ブランド設定は、**その端末のブラウザの中だけ**に保存されます。
PCとiPhoneで同じ設定にしたいときは、設定画面の「書き出す／読み込む」を使ってください。

---

## 2. ★いちばん簡単★ 画面からブランドを追加する

1. 右上の **⚙** を押す
2. 「ブランド設定」の **＋ ブランドを追加**
3. **表示名**（例：コムデギャルソン）と **検索キーワード**（例：`COMME des GARCONS, コムデギャルソン, ギャルソン`）を入れる
4. 必要なら **カテゴリー**（バッグだけ など）と **サイズ条件**（L以上 など）、**探すサイト**を選ぶ

これだけで、その端末にすぐ反映されます。

- 検索キーワードは**英語と日本語の両方**を入れると取りこぼしが減ります。
- 「サイズ不明の商品も表示する」に✓を入れると、サイズが読み取れない商品も出ます。
- 「ブランド設定を初期状態に戻す」で、いつでも最初の5ブランドに戻せます。

## 3. 全端末で共通にしたいとき（config.json）

画面から追加したブランドは、その端末だけに保存されます。
**全部の端末で最初から出るようにしたい**ときは、GitHub の `shiire-research/config.json` を編集します。
保存すると1〜2分で自動的にサイトへ反映されます。

```json
    {
      "id": "comdesgarcons",
      "label": "コムデギャルソン",
      "keywords": ["COMME des GARCONS", "コムデギャルソン", "ギャルソン"]
    }
```

| 項目 | 必須 | 意味 |
|---|---|---|
| `id` | 必須 | 英数字だけの名前（他と重ならなければ何でもOK） |
| `label` | 必須 | 画面のボタンに出る名前 |
| `keywords` | 必須 | 各サイトで検索する言葉。英語・日本語の両方を入れる |
| `category` | 任意 | 特定カテゴリーだけ出したいとき（例 `"category": "bag"`） |
| `minSize` | 任意 | このサイズ以上だけ出したいとき（例 `"minSize": "L"`） |
| `allowUnknownSize` | 任意 | `minSize` を付けたとき、サイズ不明も表示するなら `true` |
| `sites` | 任意 | 探すサイトを限定するとき（例 `["trefac","okoku"]`） |
| `offmallBrandId` | 任意 | オフモールのブランドIDを直接指定したいとき（通常は自動で判定します） |

**注意**：最後のかたまりのうしろにカンマを付けない／カッコとクォートは半角。

## 4. サイトごとの取得状況（大事）

| サイト | 状態 | 内容 |
|---|---|---|
| トレファクファッション | ✅ 自動取得 | 検索結果ページ（新着順） |
| 買取王国 | ✅ 自動取得 | 公式オンラインストアの検索結果 |
| オフモール | ✅ 自動取得 | **ブランド別一覧**（`/brand/<ID>/?s=1`）。ブランドIDは公開の一覧ページから自動判定 |
| セカンドストリート | 🔗 リンクのみ | サイト側の**アクセス制限（Akamai）でサーバーからは403**。回避はしていません |
| ブランディア | 🔗 リンクのみ | 同上 |

- オフモールは robots.txt が**検索ページ `/search/` の自動取得を禁止**しているため、
  **許可されているブランド別一覧**から取得しています。
- セカスト・ブランディアは、どんなヘッダーでも・トップページ経由でも 403（Akamai の Access Denied）でした。
  **アクセス制限の回避はしません**。画面下の「自動取得できないサイトも確認する」ボタンから、
  そのブランドの検索結果ページを開けます。上部の 🔗 バッジからも1タップで開けます。
- 状況が変わったかどうかは `/api/diag?url=...`（登録済みサイトのみ）で確認できます。
  取得できるようになったら `config.json` の `sites` でそのサイトを `"mode": "fetch"` に変えるだけです。

---

## 5. 更新とキャッシュ

- 画面を開いた時点で、サイトごとに**並行して**取得します（1つが失敗しても他は表示されます）。
- 取得結果は約45分キャッシュします。最新にしたいときは右上の **更新** を押してください。
- 上部に「最終更新 ○分前」、カードごとに「取得 ○分前」を表示します。

---

## 6. 送料・手数料

- ⚙ 設定画面で **想定送料** と **販売手数料(%)** を変更できます（初期値：850円 / 10%）。
- 予想利益 ＝ 予想販売価格 − 仕入価格 − 販売手数料 − 送料

---

## 7. 各サイトへの配慮について

- 取得するのは、**誰でも見られる公開ページだけ**です。
- アクセスの前に必ず **robots.txt を確認**し、禁止されているページは取得しません。
- ログインが必要なページ、CAPTCHA、アクセス制限の回避は**一切していません**。
- 同じサイトへの連続アクセスには間隔をあけ、403を返したサイトには30分アクセスしません。
- オフモールのブランド一覧は1日1回だけ取得してキャッシュします。

## 8. パソコンで動かしたいとき（任意）

```bash
npm install

MOCK=1 npm start   # ネットに繋がらない環境でも画面だけ確認できます

```

## 9. ファイルの中身

| ファイル | 役割 |
|---|---|
| `config.json` | ブランド設定・サイト設定（全端末共通の初期値） |
| `public/` | 画面（HTML / CSS / JavaScript / PWA） |
| `lib/sites/` | 各サイトから商品を読み取る部分 |
| `lib/` | 共通処理（robots.txt確認・キャッシュ・サイズ判定など） |
| `api/` | 商品を返すAPI（`products` はサイト単位でも取得できます）と診断用 `diag` |
| `server.js` | パソコンで動かすときのサーバー |
| `test/` | 動作チェック |

サイトのデザインが変わって商品が取れなくなったときは、`lib/sites/` の該当ファイルだけ直せば直ります。
