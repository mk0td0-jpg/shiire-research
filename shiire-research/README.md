# 仕入れリサーチ

セカンドストリート・ブランディア・トレファクファッションの**公開されている検索結果**を
1つの画面にまとめて表示する、中古ブランド品の仕入れリサーチ用サイトです。

スマホのブラウザでURLを開くだけで使えます。ログインは不要です。

---

## 1. 何ができるか

- ブランドボタンを押すと、3サイトの商品を1つの一覧に混ぜて表示
- カードに 画像・ブランド・商品名・税込価格・サイズ・状態・販売サイト名 を表示
- カードをタップすると、元の商品ページが新しいタブで開く
- 並び替え：**新着順（初期設定）／価格が安い順／価格が高い順**
- 絞り込み：販売サイト／価格／サイズ／キーワード
- **× 興味なし**：一覧から消える（ブラウザを閉じても維持）
- **☆ お気に入り**：あとでまとめて確認できる
- **◎ 仕入れ候補**：予想販売価格とメモを入力すると**予想利益を自動計算**
- **NEW**：前回見たときより後に増えた商品に印がつく（「NEWのみ」ボタンで新着だけ表示）
- 「商品を更新」ボタンと「最終更新 ○時○分」の表示

お気に入り・仕入れ候補・興味なしは、**そのスマホのブラウザの中だけ**に保存されます
（アカウント登録は不要ですが、別の端末とは共有されません）。

---

## 2. ★いちばん大事★ 新しいブランドを追加する方法

編集するのは **`config.json` というファイル1つだけ** です。

### 手順

1. `config.json` を開きます。
2. `"brands": [` の中に、**カンマ `,` で区切って**次のかたまりを追加します。

```json
    {
      "id": "comdesgarcons",
      "label": "コムデギャルソン",
      "keywords": ["COMME des GARCONS", "コムデギャルソン", "ギャルソン"]
    }
```

3. 保存すれば完了です。画面にボタンが増えます。

### 書き方の説明

| 項目 | 必須 | 意味 |
|---|---|---|
| `id` | 必須 | 英数字だけの名前。他と重ならなければ何でもOK（例 `auralee`） |
| `label` | 必須 | 画面のボタンに出る名前（例 `オーラリー`） |
| `keywords` | 必須 | 各サイトで検索する言葉。**英語・日本語の両方**を入れると取りこぼしが減ります |
| `category` | 任意 | 特定カテゴリーだけ出したいとき（例 `"category": "bag"`） |
| `minSize` | 任意 | このサイズ以上だけ出したいとき（例 `"minSize": "L"`） |
| `allowUnknownSize` | 任意 | `minSize` を付けたとき、**サイズ不明の商品も表示**したいなら `true`（既定は非表示） |

### 書き方の例

**バッグだけ表示したい**

```json
    {
      "id": "anteprima",
      "label": "アンテプリマ",
      "keywords": ["ANTEPRIMA", "アンテプリマ"],
      "category": "bag"
    }
```

**Lサイズ以上だけ表示したい**

```json
    {
      "id": "wackomaria",
      "label": "ワコマリア",
      "keywords": ["WACKO MARIA", "ワコマリア"],
      "minSize": "L"
    }
```

**全部表示したい（何も付けない）**

```json
    {
      "id": "auralee",
      "label": "オーラリー",
      "keywords": ["AURALEE", "オーラリー"]
    }
```

### 注意（よくある失敗）

- **最後のかたまりのうしろにカンマを付けない**でください。
- カッコ `{ }` `[ ]` とダブルクォート `" "` は必ず半角で。
- 保存したあと画面がおかしくなったら、たいていカンマの付け忘れ・付けすぎです。

## 3. カテゴリーを増やしたいとき

`config.json` の `"categories"` に追加します。
`include` に入れた言葉が商品名に含まれていれば表示、`exclude` の言葉が入っていれば除外します。

```json
    "knit": {
      "label": "ニット",
      "include": ["ニット", "セーター", "カーディガン"],
      "exclude": []
    }
```

そのうえで、ブランド側に `"category": "knit"` と書けば使えます。

---

## 4. 送料・手数料を変える

- 画面の「◎ 仕入れ候補」タブを開くと、**想定送料**と**販売手数料(%)**をその場で変更できます（初期値：送料850円・手数料10%）。
- 全員の初期値そのものを変えたいときは `config.json` の `settings.shippingCost` / `settings.feeRate` を編集します。

予想利益 ＝ 予想販売価格 − 仕入価格 − 販売手数料 − 送料

---

## 5. その他の設定（`config.json` の `settings`）

| 項目 | 意味 | 初期値 |
|---|---|---|
| `shippingCost` | 想定送料（円） | 850 |
| `feeRate` | 販売手数料（0.1 = 10%） | 0.1 |
| `cacheMinutes` | 取得結果をためておく時間（分） | 45 |
| `requestIntervalMs` | 各サイトへのアクセス間隔（ミリ秒） | 800 |
| `requestTimeoutMs` | 1回の取得の待ち時間の上限 | 12000 |
| `maxItemsPerSource` | 1サイトあたりの最大件数 | 120 |

## 6. サイトごとの取得状況（大事）

| サイト | 状態 |
|---|---|
| トレファクファッション | **自動で商品を取得できます**（一覧に混ざって表示されます） |
| 買取王国 | **自動で商品を取得できます**（一覧に混ざって表示されます） |
| セカンドストリート | サーバーからの自動取得を受け付けていません（403） |
| ブランディア | サーバーからの自動取得を受け付けていません（403） |
| オフモール | サイトのルール（robots.txt）で検索ページの自動取得が禁止されているため取得しません |

セカンドストリートとブランディアはサイト側がプログラムからのアクセスを拒否しており、
オフモールは robots.txt で検索ページの自動取得を認めていません。
**これらの制限を回避することはしていません。** 代わりに画面の上部に

「セカストで『アンテプリマ』を検索　開く →」

というボタンを出しています。押すと、選んでいるブランドの検索結果ページがそのまま開きます。
（一度403になったサイトには30分間アクセスしないようにしているので、サイトに負担はかかりません。）

将来サイト側の対応が変わって取得できるようになった場合は、自動的に一覧に混ざって表示されます。

※ 買取王国は商品名の最後にサイズが書かれている場合だけサイズを表示します（例「ジャケット WACKO MARIA ジャケット M」）。
サイズが分からない商品は `minSize` を付けたブランドでは非表示になります。全部見たいときは
そのブランドに `"allowUnknownSize": true` を足してください。

---

## 7. 各サイトへの配慮について

- 取得するのは、**誰でも見られる検索結果ページだけ**です。
- アクセスの前に必ず **robots.txt を確認**し、禁止されているページは取得しません。
- ログインが必要なページ、CAPTCHA、アクセス制限の回避は**一切していません**。
- 同じサイトへの連続アクセスには間隔をあけ、取得結果は45分間キャッシュして
  何度も同じアクセスをしないようにしています。
- あるサイトが取得できなかったときは、そのサイトだけ小さくエラー表示し、
  「サイトで見る →」から**そのサイトの検索結果ページを開くリンク**を出します。
  他の2サイトの商品はそのまま表示されます。

---

## 8. パソコンで動かしたいとき（任意）

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開きます。

ネットにつながらない環境で画面だけ確認したいときは `MOCK=1 npm start`（ダミー商品が表示されます）。

動作チェック（パーサーのテスト）は `npm test` です。

---

## 9. ファイルの中身

| ファイル | 役割 |
|---|---|
| `config.json` | **ブランド設定（普段さわるのはここだけ）** |
| `public/` | 画面（HTML / CSS / JavaScript） |
| `lib/sites/` | 各サイトから商品を読み取る部分 |
| `lib/` | 共通処理（robots.txt確認・キャッシュ・サイズ判定など） |
| `api/` | 商品を返すAPI |
| `server.js` | パソコンで動かすときのサーバー |
| `test/` | 動作チェック |

サイトのデザインが変わって商品が取れなくなったときは `lib/sites/` の中の
該当ファイルだけを直せば直ります。
